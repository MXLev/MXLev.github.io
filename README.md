# Лев Скуратов / MXLev

Личный сайт на GitHub Pages. HTML, CSS и JavaScript без сборки и зависимостей.

## Локальный запуск

В каталоге проекта: `python -m http.server 4173 --bind 127.0.0.1`

Открыть http://127.0.0.1:4173.

## Обновление

- `index.html` — тексты, проекты и разделы.
- `content.js` — материалы подготовки. Добавляй объекты с названием, описанием, категорией (`math`, `code`, `robotics`), типом и HTTPS-ссылкой.
- `style.css` — оформление и адаптивность.
- `app.js` — поиск, фильтры и визуализация.

Личные папки Google Диска пока не подключены. Для закрытых материалов выставляй доступ конкретным пользователям на самом Диске. Не добавляй закрытые документы или секреты в публичный репозиторий. Названия и ссылки из `content.js` публичны.

Фото и музыка подключены из присланных файлов. Блок TGFocus содержит эскиз интерфейса, не скриншот приложения. Репозиторий мобильных роботов обозначен как учебный.

## GitHub Pages

Репозиторий `MXLev.github.io`, ветка `main`, публикация из `/ (root)` через Settings → Pages → Deploy from a branch. Сайт доступен по https://mxlev.github.io/. Файл `.nojekyll` отключает обработку Jekyll. Отдельный сервер и ключи не нужны.

Google Fonts — единственный внешний ресурс оформления. При отсутствии сети используются системные шрифты. Аналитики и трекеров нет.


## Галерея и музыка

- 72 фотографии в двух сериях: 18.10.2026 и 21.10.2026 (названия папок исходного архива).
- Превью WebP до 640 px; крупные версии до 2200 px. Ориентация применена, EXIF и координаты в веб-копии не переносятся.
- Изначально показаны 6 избранных фотографий, кнопка раскрывает остальные по 12. Есть фильтр серий, диалог просмотра, стрелки, Escape и свайпы.
- 7 треков с оригинальными встроенными обложками и названиями из ID3. Кавер «Спокойная ночь» отмечен отдельно.
- MP3 загружаются по требованию. Одновременно играет один трек. Аудиопотоки сохранены без перекодирования; из копий удалены повторные встроенные обложки и производственные метаданные.
- media-data.js — список фотографий, треков и ссылок. media.js и media.css — интерфейс.
- Для локального просмотра можно открыть index.html; рейтинг Codeforces требует интернета.

Проверены сценарии галереи, фильтры, просмотр и навигация, переключение вкладок, пауза предыдущего трека, обработка ошибки, все пути к файлам и целостность аудиопотоков. В браузере проверены загрузка фотографий, крупный просмотр, перелистывание, воспроизведение и остановка предыдущего трека.

Треки Meaningless pain объединены под общей обложкой; Rain-mist Cycle и кавер показаны отдельно.
